# 测试样本

全部是本项目自己写的或本项目生成器的输出，用来测试 CK3 代码的解析和序列化（`test/coa.test.ts`）。

| 文件 | 内容 |
|---|---|
| `designer-export.txt` | 游戏内设计器导出的格式：注释、键名、三种颜色、一个图层多个实例、蒙版贴图 |
| `colours.txt` | 各种颜色写法：命名颜色、`rgb`、`hsv`（0–1）、`hsv360` |
| `transforms.txt` | 旋转、负缩放（镜像）、紧凑和带空格两种写法、没有 `instance` 块的图层 |
| `generated-*.txt` | 本项目生成器的输出：恩赐纹章、领地四分加中盾、带裁切方块的小盾 |
