# 设计

## 页面结构

整个网站是一个页面（`index.html` + `src/app.ts`），网址里的 `?p=` 决定显示哪个视图（`src/routes.ts`）：

| `?p=` | 视图 | `#` 后面 |
|---|---|---|
| （无） | 首页：按身份和地域分流到设计器 | — |
| `west` | 西欧统治者设计器 | 回答（分享链接就是网址） |
| `examples`、`rules`、`license` | 示例、规则与出处、版权与许可 | 页内锚点 |

切换视图用 History API，不刷新页面：载入的游戏贴图和进行中的设计都会保留，后退和前进照常可用。没有 `?p=` 但 `#` 后面带着回答的旧链接，按西欧设计器打开。

**为什么分成多个设计器。** 各身份、各地域的徽记规则差别很大（西欧的纹章、教会的对分、草原的 tamga、日本的家纹），放进同一套题目会互相牵制。所以每种各做一个设计器，有自己的答案、题目、生成器和元素对照（如 `src/west/`），通过 `Designer` 接口（`src/designer/types.ts`）交给共用视图 `src/designer/page.ts`。共用部分是预览、候选、说明、元素对照表、CK3 代码、本地保存、分享和游戏贴图预览。首页的分流目标和规划中的设计器在 `src/pages/destinations.ts`。

**美术风格**（全部在 `src/theme/`）：
- 底色是羊皮纸，颜料取自抄本的红丹、群青和贝壳金；暗色模式是烛光下的同一本书。
- 每个传统的左右页边各有一幅 CK3 年代（867–1453）的人物或军队画，清单和许可在 `src/theme/art/credits.ts`。画都转成单色墨迹（`tools/ink_picture.py`），作为蒙版用页面的墨色印出，边缘羽化，看起来像同一本抄本里的插图。画按原比例完整显示，贴着正文外沿，不压正文；页边太窄时隐藏。
- 首页背景随选择淡入淡出，换成目标页面的画（系统要求减少动态效果时直接切换）；没有规划的组合显示波特兰海图。
- 框体按页面区分：西欧设计器是抄本的一页，示例是纹章卷轴，规则是论著的书页，版权是一张特许状；首页卡片用各传统的材质色块。纹样是原创 SVG 蒙版，颜色来自 CSS 变量。
- 不加载外部字体。

下文写的都是西欧统治者设计器（`src/west/`）。

## 数据流

```
答案 (Answers)                         src/west/answers.ts，存在网址里（分享链接 = 网址；本地保存 = 名字 + 网址片段，src/designer/saved.ts）
  └─ generate()                        src/west/generate.ts
       └─ 若干合规候选 (Candidate)       每个带一份 Arms（结构化 blazon，src/heraldry/ast.ts）
            ├─ checkArms()             色彩规则（测试用它证明生成器不出错）
            ├─ blazon()                英文纹章术语描述
            ├─ describe()              用界面语言描述（src/describe.ts + i18n）
            └─ layout()                src/layout.ts → 带坐标的绘制节点
                 ├─ renderSvg()        网页预览，自绘图案（src/art/）
                 └─ exportCk3()        CK3 代码，只用原版贴图
                      └─ renderCoa()   可选：用玩家本机的游戏贴图在浏览器里精确预览
```

核心数据是**结构化的 blazon**，不是图片，也不是 CK3 代码。SVG 和 CK3 代码都由同一份 `layout()` 结果生成，所以两边位置一致，只是画风不同。

## 题库

每道题对应一种真实存在过的纹章机制。纹章本身没有"象征含义词典"，所以图案的含义由持有者自己定，网站不替玩家编。

| 题目 | 纹章机制 | 生成时的作用 |
|---|---|---|
| 家族名 | — | 决定默认用哪种几何图形、盾面分割、条纹、毛皮和线条，让不同存档的结果不同 |
| 年份 | 年代规则 | 决定各王国当时的纹章、哪些选项可用；1150 年前提示纹章尚未出现 |
| 领主 | 派生纹章、capo | 配色默认沿用领主颜色；可借用领主的主图案；生成"领主盾头"候选 |
| 主图案 | 持有者自选 | 系列 → 变体两级选择 |
| 起家方式 | 起源与谐音纹章 | 城堡、港口、森林、战功、商贸、农牧、教会，各对应几个图案 |
| 信仰标志 | 宗教图案 | 依次尝试：鹰胸前 → 盾头正中 → 角区 → 几何图形上；没有主图案、起家图案或事迹图案时，它就是家族的图案本身（如匈牙利的双横十字），按主图案排 |
| 事迹 | 荣誉增补、恩赐纹章 | 十字军 → 十字端十字；朝圣按目的地用朝圣者带回的徽记：圣地亚哥 → 扇贝，罗马 → 交叉钥匙，耶路撒冷 → 耶路撒冷十字（朝圣地随信仰不同，目前只收录拉丁基督教世界这三处）；为领主立功 → 带领主纹章的恩赐角区，或领主赐的新纹章（金属底、十字、四角各一个领主的图案，家族纹章作中盾；最多出两个候选） |
| 爵位 | 组合顺序 | 领主：家族纹章在前；国王、皇帝：领地在前，家族作中盾 |
| 现有头衔 | 领地纹章（arms of dominion） | 先列出爵位能持有的头衔（同级或更低，和 CK3 一样：爵位就是最高头衔），更高的折叠在下面，选了会提示；最多 3 个（1435 年起 5 个，不考虑历史时 7 个），按点选顺序分区，见下文"组合" |
| 宣称 | 宣称纹章 | 鹰胸前小盾 / 正中小盾 / 与王国纹章四分；有头衔时并入分区，排在头衔之后 |
| 家族位置 | 区分标记 | 三尖带、新月、五角星、燕、圆环、斜短带 |
| 风格 | — | 只影响候选的排序 |
| 几何图形与线条 | — | 不按家族名，直接指定几何图形、分割、条纹、毛皮、散布底、线条（`geom`，见下文"几何图形的指定"） |
| 配色 | 色彩规则 | 先列出"一金属一颜色"的合规搭配，外加白鼬皮底；违规的折叠在下面（armes à enquérir），选了会保留违规之处并注明；第三色可以指定，见下文"第三色" |

## 不考虑历史真实性

右上角的勾选框（`Answers.free`，网址里是 `x=true`）只解除年代的限制：

| 限制 | 平时 | 打开后 |
|---|---|---|
| 王国纹章 | 按年份给纹章；早于最早的纹章时提示时代不符 | 任何年份都用最接近的纹章，不提示 |
| 晚期做法 | 年份到了才用（见下文"晚期做法与年代开关"）：1370 年起左右对分，1435 年起六区 | 任何年份都能用：左右对分，组合最多八区 |

另外两种限制性质不同，不用开关：

| 限制 | 性质 | 做法 |
|---|---|---|
| 色彩规则 | 纹章学的约定。违规的纹章真实存在（耶路撒冷），只是少见，所以不算"不符合历史" | 违规的配色折叠在合规配色下面，展开就能选；选了的话，违规的候选保留 |
| 爵位与头衔 | CK3 的规则：爵位就是最高的头衔 | 超出爵位的头衔折叠在能持有的头衔下面，展开就能选；没有封地时头衔题照样显示 |

折叠的一组在当前答案正好在里面时默认展开。

结果违反色彩规则时（选了违规的配色，或者细节颜色让三峰山和底色同类），提示里会说明什么放在什么上面，并注明英法纹章学的叫法：armes fausses（错误的纹章）或 armes à enquérir（引人追问的纹章），违规被看作请人追问来历的邀请。选中的纹章里有本身违规的历史王国纹章时（耶路撒冷、安茹-西西里），也会这样注明（`note.armesFausses`、`note.armesAEnquerir`）。出处：Wikipedia, *Rule of tincture*。持有超出爵位的头衔时，提示 CK3 里持有它就会升到那一级（`note.aboveRank`）。

CK3 的技术限制和本站的约定不受影响：小盾只放 `escutcheonSafe()` 认可的纹章（CK3 不能裁切），图案不重叠。关掉勾选框或把年份改早时，放不进四区（或六区）的头衔会被清掉。

## 晚期做法与年代开关

比其余做法晚出现的东西也做，按年代开放（[路线图](roadmap.md)开头的"年代"）。`src/heraldry/era.ts` 的 `LATE` 记下每一项最早有出处的年份，`opens(k, { year, free })` 判断这一年能不能用：年份早于它时不用，勾选"不考虑历史真实性"时总能用；1453 年以前找不到出处的记为 `null`，只在后者下出现。出处放在 `src/pages/sources.ts` 的 `LATE_SOURCES`，`test/data.test.ts` 检查每个有年份的项都有出处。

| 做法 | 年份 | 出处 |
|---|---|---|
| 左右对分（`impalement`） | 1370 | Gelre 纹章卷（约 1370–1414）f. 62r 646、647：阿拉贡支系的乌赫尔、恩普里亚斯伯爵；13 世纪的卷里没有。Fox-Davies 说更早的"各取半面"（dimidiation）主要流行于 14 世纪前期 |
| 六区（`quarterlyOfSix`） | 1435 | 昂儒的勒内：*Armorial de l'Europe et de la Toison d'or* f. 100；他的时祷书 f. 4v（1442–43）；blazon 见剑桥王后学院的纹章页 |
| 八区（`quarterlyOfEight`） | 无 | 1453 年以前没有找到 |

加一项：在 `LATE` 里加键和年份，在 `LATE_SOURCES` 里加出处，生成器里用 `opens()` 判断，再在本节的表里补一行。

## 生成器

1. **基本排法**（`templates()`）。根据主图案 A、第二图案 B 列出排法：
   - 单一图案：居中；小图案默认三个，按两上一下排列。
   - 几何图形加周围图案、几何图形上放图案。
   - 内框、条纹底加盾头、条纹底加小盾、毛皮底加盾头（见下文"毛皮"）、散布底加主图案（见下文"散布底"）。
   - 上下排、盾头、角区、左右分、上下分。
   - 领主盾头。
   - 什么图案都没有时，只用几何图形、盾面分割、条纹、毛皮或散布底；松鼠皮和散布底还有"加一道几何图形"。
2. **装饰**：依次放事迹、信仰标志、宣称、区分标记。抢位置时，每种合规解法各成一个候选；放不下的愿望记在 `dropped` 里，界面上会明说。
3. **避让**：三尖带和小区分标记需要盾面顶部一条空带。主图案会下移；有盾头、角区或"周围图案"的排法会和顶部重叠，这些排法放弃区分标记，而不是叠在一起。新月、五角星这类小标记只放在底色上：生成器把它试放到排好的纹章上，压到几何图形（竖带、十字、内框……）就放弃（`markCovers()`，`src/lint.ts`）。标记的位置随组合而变（两列时在分割线上，碰的是两侧区的内上角；三列时在中间一区里），所以按实际排版判断，不列清单。三尖带横跨盾顶、压在几何图形上面，照旧保留。斜短带本来就是压在整个盾面上的，不受这条限制。
4. **撞车**：和收录的王国在任何年代用过的纹章完全一样时，照样保留（玩家可能扮演的就是这个家族或王国，或者想在它的纹章出现之前就用），但在主盾下方醒目地提示"这是某某的纹章"，候选缩略图上加"!"。
5. **校验与排序**：去掉违规和重复的候选；按"放弃的愿望数 → 风格偏好 → 排法顺序"排序，最多保留 16 个。
6. **记住选择**：答案里存的是排法的 id（如 `chief#0`），不是第几个。改动其他答案后，依次找同一个排法、同一种基本排法、同一类排法（如 `between-*`），都没有才退回第一个。

每种排法都有纹章学的名字（`lname.*`）：

| 名字 | 对应 |
|---|---|
| 单图式 | a single charge |
| 三图式 | three, two and one |
| 三图竖排 / 横排 / 斜排 | three in pale / in fess / in bend：宽的图案（如正面行狮）竖排，高的（如钥匙）横排 |
| 六图式（三二一） | six, three, two and one；只用于小图案 |
| 山形带间饰 等 | a chevron between … |
| 横带上饰 等 | on a fess … |
| 内框式 | within an orle |
| 上下式 | in chief and in base |
| 盾头式 | on a chief |
| 角区式 | a canton |
| 纵分式、横分式 | per pale、per fess |
| 领主盾头 | capo |

宣称以"四分 · …""… · 加中盾""… · 加胸盾"的形式标在名字上。

## 组合（marshalling）

组合的纹章放在 `quarterly` 里：`q` 是各区的纹章，`of` 注明哪一区是哪个王国的。区按排编号，从左上起先排完上排。

| 形状 | 纹章数 | 年代 | 排法 |
|---|---|---|---|
| 左右对分（impaled） | 2 | 1370 年起 | 左边（持盾人的右手边）是尊位 |
| 四分 | 2–4 | 一直可用 | 两面 1、4 / 2、3，三面 1、4 / 2 / 3，四面各一区 |
| 六区（两排各三区） | 5–6 | 1435 年起 | 单数时第一面在最后一区重复，和三面排 1、4 / 2 / 3 是同一个道理 |
| 八区（两排各四区） | 7–8 | 只在不考虑历史时 | 同上 |

年代见上文"晚期做法与年代开关"（`maxQuarters()`）。再多的放不下，记为放弃的愿望；头衔题的上限（`maxTitles()`）比区数少一，留一区给家族纹章。描述和 blazon 会把相同的区合并（"第 1、4 区"），六区写作 "Quarterly of six"，左右对分写作 "Per pale: dexter …; sinister …"。

区数的上限是本站的约定，不是 CK3 的限制（导出的代码都是方块和贴图，分几区都画得出），依据是史料：到 15 世纪初的卷里没有超过四区的组合，纹章多了是在一区里再分，左右对分两面，或者放进一面本身已四分的纹章（[roll-gaps.md](roll-gaps.md#组合)）；最早的六区是昂儒的勒内 1435 年起用的。我们的区里再四分只有后一种来源：领地纹章本身就是四分（卡斯蒂利亚-莱昂）。一区里的左右对分同样只来自领地纹章本身：1301–1382 年安茹家的匈牙利是条纹对分法兰西百合（照 Gelre 500），放进区里时两半各铺满一条竖条。

**左右对分。** 只有两面纹章时（一个头衔，或者没有头衔只有一个宣称）多一个候选：伯爵、公爵把家族纹章放左边（Gelre 646：阿拉贡对分乌赫尔），国王、皇帝把领地放左边，宣称的王国也放左边（Gelre 310：安茹的路易二世，耶路撒冷对分安茹）。每种排法都加的话，十六个候选里会挤掉别的排法，所以只给排在最前的两种排法加。

**排版。** 每一区的图案放在区内贴着上边、不出盾形的最大矩形里（`insideShield()`），盾形是整面大盾的轮廓，在小盾里就是小盾的轮廓（`Frame`）。整面盾左右对分时例外：两半各是一整面横向压窄的纹章（这正是对分和"各取半面"的区别），几何图形、盾头、角区从盾顶到盾底铺满整个半边，图案照整面盾的位置落在盾心高度，不挤在半边顶上那块方形里，有区分标记时只有图案让出标记带（`Opts.whole`）；盾底的弧线只削去半边外侧的下角，图案不被切掉由排版检查保证。上排的图案让出区分标记的位置。正中有小盾时，各区的图案放在避开小盾轮廓的最大一块里（`clearOf()`），小盾下半收窄，所以下排的区让出一些高度就能换来更宽的地方。三列时盾顶正中落在中间一区里，而不是两区之间的分割线上，所以中间一区有竖带、十字、pile、内框之类时不加区分标记。

内框、双重内框里的图案跟着圈走：先照整面盾的位置放在圈所在的框里，再以这一点为中心等比缩小，直到让开盾头、区分标记带或正中小盾占去的地方。以中心等比缩小，图案就留在它在整面盾上的轮廓里，不会滑到圈上；最多缩到原来的七成左右。荣誉增补的角区不加到有内框的排法上：它正好盖住圈里的左上角，留给图案的地方太小，这时记为放弃，由别的排法带上。

区里嵌着一面四分纹章时（卡斯蒂利亚-莱昂），在四区、六区、八区的区里它整体缩进这一区不出盾形的部分，露出的部分涂第一区的底色；在左右对分的半边里，它铺满整个半边，各子区再各自按盾形收边（`Opts.tile`）。嵌着的是左右对分的纹章时（安茹家的匈牙利），两半总是铺满所在的区。散布的图案在盾的外缘可以伸出一半（由盾形裁掉），在盾面内部的分割线上不伸出：CK3 不能裁切，越过分割线的部分会压到隔壁。嵌在区里的分区标签带着外层的前缀（`q2-q1`），因为导出时整面的第 1 区和最后一区由背景图案代画，标签同名的块会被跳过。组合的纹章不放上小盾（`escutcheonSafe()` 只认四分），也不会嵌进别的区里：没有王国本身用对分、六区或八区。

| 身份 | 候选 |
|---|---|
| 无封地、伯爵、公爵 | 家族纹章在第 1 区，头衔（和宣称）依次排在后面 |
| 国王、皇帝 | ① 领地纹章分区，家族纹章作正中小盾（en surtout）；只有一个领地时，要求它正中是空的 ② 家族纹章作为一区，排在领地之后 |
| 持有神圣罗马帝国的皇帝 | 另加：帝国鹰胸前托家族纹章（其余头衔放不下） |

历史上的王国纹章按原样使用：规则检查跳过注明了王国的区和小盾（安茹-西西里的红色三尖带压在蓝底上，本身就违反色彩规则），只检查玩家自己的部分。

**小盾在 CK3 里的限制。** CK3 不能裁切图层，所以只有 `escutcheonSafe()` 认可的纹章才会放上小盾：纯色底（白鼬皮除外）、方块能拼出的分割（左右分、上下分、四分、横条、竖条、方格）、横带、竖带、十字、四条竖带、内框、双重内框，以及盾头和角区。导出时，小盾里的方块会切成横条，沿着从 `ce_escutcheon` 量出的轮廓收窄（`TEX.escutcheon.edge`）。斜向的贴图、散布图案和白鼬皮做不到这一点，所以不放上小盾。

## 问题分类与元素对照

问题分三组（`SECTIONS`，`src/west/questions.ts`）：

| 类别 | 问题 | 含义 |
|---|---|---|
| 生平 | 家族名、年份、领主、爵位、头衔、宣称、事迹、家族位置 | 角色在游戏里的事实，将来可以从存档读取 |
| 自选 | 主图案、起家方式、信仰标志 | 家族的象征，由玩家决定 |
| 审美 | 风格、几何图形与线条、配色 | 只影响外观和排序 |

结果页的"元素对照"表由 `src/west/legend.ts` 生成。它从选中的纹章倒推每个元素来自哪个回答，所以只列盾上实际有的东西。表中还有第四类"自动"：几何图形和分割由家族名决定，没有含义；玩家在"几何图形与线条"里指定了的，归入"审美"。

## 线条与细带

几何图形、盾头和分割可以带线条（`Line`），但只用在 CK3 原版有对应贴图的地方（`LINES`，`src/heraldry/ast.ts`）：

| 对象 | 线条 | 原版贴图 |
|---|---|---|
| 十字 | 弧齿边 engrailed | `ce_cross_engrailed` |
| 横带 | 弧齿边、大锯齿 dancetty | `ce_fess_engrailed`、`ce_fess_dancetty` |
| 斜带 | 弧齿边、城垛 embattled | `ce_bend_engrailed`、`ce_bend_embattled` |
| 盾头 | 锯齿 indented | `ce_chief_indented_alpha`（`ce_chief_indented` 会连底色一起画，不用） |
| 上下分 | 锯齿 | `ce_per_fess_indented` |
| 右斜分 | 云纹 nebuly | `ce_per_bend_nebuly` |

| 横带、斜带 | 菱形连缀 fusilly（fusils conjoined） | `ce_fess_lozenges`、`ce_bend_lozenges` |

线条由家族名决定，和几何图形的种类一样；每个家族只有第一个几何图形、盾头和分割会带线条，第二个保持直线。大锯齿、城垛和菱形连缀上面不放图案（放不下），弧齿边可以。带线条的纹章不放上 CK3 的小盾（裁不了）。

**细带与复数几何图形。** 纹章卷里常见几道细带或几道同样的几何图形单独成纹（Argent, two chevrons gules；Or, five bendlets gules）。现在支持：

| 几何图形 | blazon | 画法 |
|---|---|---|
| 三道横条、两组双细横条、六道细横条、三道竖条 | three bars, two bars gemel, six barrulets, three pallets | 方块拼（`BAND_ORDINARIES`），比例照 `ce_bars_03`、`ce_bars_gemel_03`、`ce_pales_03`；能放上小盾 |
| 两道斜带，三、四、五道细斜带 | two bends, three / four / five bendlets | `ce_bends_02`–`05` |
| 两道山形带、横带夹两道山形带 | two chevrons, a fess between two chevrons | `ce_ordinary_chevron_2`、`ce_fess_betw_two_chevrons` |

横的、竖的本来就是矩形，用方块拼最准，也能在小盾里按轮廓裁成横条；原版的 `ce_barrulets_2` 是两道相隔很远的细条，拼不出成对的双细横条。斜的、折的方块拼不出来（CK3 先旋转再按盾面坐标缩放，旋转过的方块拉不成斜条），所以用原版贴图，网页预览和排版检查用的多边形是沿贴图量出来的（`ORDINARY_POLYS`）。

这些几何图形上面和周围都放不下图案：有图案时改用它们所缩小或重复的那一种（`DIMINISHES`，`src/west/questions.ts`：两道横条、三道横条、双细横条、细横条、横带夹山形带 → 横带，两道、三道山形带 → 山形带，几道斜带 → 斜带，三道竖条 → 竖带）。它们比轮换里的前九种少见，所以家族名不会选到（`ORD_BY_NAME`），只能在"几何图形与线条"里指定。还没做的是要拼的那些：两侧细边 cotises、三个倒三角、镂空十字、回纹、三组双细横条。

菱形连缀其实不是线条，而是由菱形连成的横带或斜带。13 世纪的纹章卷就写作 "a bend fusily"，1864 年的校订者也说这类纹章最早的 blazon 就是 "fess / bend engrailed"。它占的位置和用法都和带线条的横带、斜带一样，所以按线条处理。原版贴图是七个竖立的菱形，并排连在一起（纹章卷里多是五个）；斜带版是把这一排转 45°，宽度约是普通斜带的两倍。

## 毛皮

除了白鼬皮，13 世纪的纹章卷里常见两种（[roll-gaps.md](roll-gaps.md)）：
- **松鼠皮** vair：一排排交错的钟形，银蓝两色时就叫 vair，其他两色叫 vairy（如费勒斯的金红）。原版 `ce_vairy` 的 color1 是朝上的钟，原版头衔也都把金属色放在 color1，所以金属色写在前面。
- **网格** fretty：底色上铺满交叉的细斜带，blazon 先写底色（Gules fretty Or）。原版 `ce_fretty`。

按纹章卷里的用法生成，不和条纹底共用排法：
- 毛皮底单独成纹（费勒斯 Vairy Or and gules，奥德利 Gules fretty Or）。
- 松鼠皮底加一道几何图形（马米恩 Vair, a fess gules）。几何图形用配色以外的第三种颜色（见"第三色"）：毛皮本身两色都有，放哪一种都会混进去。
- 有图案时，毛皮底加盾头，图案在盾头上：松鼠皮配第三种颜色的盾头、金属色图案（vair, on a chief gules two mullets or）；网格配网格颜色的盾头、底色图案（St Amand 家）。

松鼠皮、网格都铺满整块方框，没法裁成小盾的形状，所以不放上 CK3 的小盾。

## 散布底

纹章卷里约十分之一的纹章用散布底（semé）：散布十字 crusilly 49 面、长方块 billetty 22 面、圆片 bezanty / platy 15 面（[roll-gaps.md](roll-gaps.md)）。用法也很固定：
- 散布的图案和压在上面的东西同色：Gules crusilly, a lion rampant Or（Hoptone），Azure billetty Or, a bend Or。
- 上面放一个主图案（小图案三个），或一道几何图形，或者什么都不放（Sable bezanty，Zouche）。
- 有两个图案、其中一个能散布（十字端十字、长方块、圆片、百合花）时，它散布在底上，另一个居中。所以事迹选"十字军"时，十字端十字可以散布在底上。

blazon 用纹章卷里的词：crusilly、billetty；金色圆片是 bezanty，银色是 platy，其他颜色写 semé of torteaux 之类。

散布哪种图案默认由家族名决定，比例大致照纹章卷：十字一半、长方块三分之一、圆片六分之一（`SEMY_BY_NAME`）。散布百合花只在指定时出现：在家族纹章上少见，金底蓝色的又正是法兰西王室纹章。散布的图案压在主图案下面，被挡住的只露出一部分，和中世纪的画法一样。

散布底不放上 CK3 的小盾（图案会被盾形切开，裁不了）；顶部也挤满了散布的图案，所以不加三尖带和小区分标记，界面上会说明放弃了哪个愿望。

## 几何图形的指定

几何图形、分割、条纹、毛皮、散布底和线条默认由家族名的哈希决定，同一个名字总得到同样的结果。玩家可以在"几何图形与线条"里逐项指定（`Answers.geom`，网址里的 `g`，如 `g=ord:fess,line:fusilly`），可选的值和名字轮换的顺序都在 `GEOM`（`src/west/questions.ts`）。指定了几何图形，第二个几何图形就取轮换里的下一个。两道横条、三道山形细带放不下周围的图案，所以有图案的排法改用它们对应的横带、山形带。线条只用在原版有贴图的地方，其余保持直线；选"直线"则全部不带线条。

改动轮换（加新种类、调顺序）会改变许多家族的默认纹章，目前不保证旧的分享链接还原出同样的结果。示例页的例子都用 `geom` 固定几何图形，不靠名字碰运气，所以生成器改了以后示例不会跟着变。

新增的几何图形：两道横条（`ce_ordinary_bars_2`）、三道山形细带（`ce_ordinary_chevron_3`）、叉形带（`ce_ordinary_pall_5`，周围可放三个图案）；新增的分割：锯齿横条纹（`ce_barry_indented`）、十道横条（`pattern_barruly_10`，用于卢森堡）。两道横条和山形细带只在没有图案时出现。

## 第三色

有几种排法要用配色以外的第三种颜色：条纹底上的盾头、角区和小盾，松鼠皮底上的盾头和几何图形。默认由生成器挑（`sameClass()`）：条纹底上取和底色同类、又不同于配色两色的第一个（颜色按蓝、红、黑、绿、紫，金属按银、金），松鼠皮上取另一种颜色。

玩家可以在配色下面指定第三色（`Answers.third`，网址里的 `p3`，如 `p3=vert`）。金属和颜色都可以选，只要不同于配色两色；白鼬皮底算银色，因为条纹和图案都用银色代替它。放在第三色上的图案改用配色两色里能和它对比的那个，所以仍然合规。例如银红条纹底配蓝色盾头，盾头上的图案就用银色：Barry of six argent and gules; on a chief azure a lion rampant argent。区分标记如果能和底色对比，也用第三色，不能时照旧自动挑。

指定的第三色和配色两色撞了（改了配色，或者沿用领主颜色时换了领主）就退回自动。选择本身留在答案里，换回合适的配色时恢复，这和选中的排法一样。元素对照表在第三色确实上了盾时加一行，归入"审美"。

## 排版检查

`src/lint.ts` 在绘制节点上检查以下几类问题：
- 图案互相重叠；
- 图案压到不属于它的盾头、角区、几何图形、区分标记带或小盾；
- 图案被盾形边缘切掉；
- 左右分、上下分的盾面上，按某一半的颜色配色的图案没有落在那一半上（`wrong-half`）。

左右分、上下分的两个图案各放在自己那一半里不出盾形的部分（`halfOf()`）：区里可用的矩形不一定以区为中心，分割线却在区的正中，所以按每一半单独取。两半再取成一样的：左右分的两个图案高度、大小相同，到分割线的距离相同；上下分的两个图案左右对齐。有中盾时，两半各自避开中盾。测试抽样检查这几点，并要求图案不小于所在一半的五分之一。

方法是在每个图案框内取点采样。几何图形的形状先裁到它自己的框里：CK3 的贴图画不出框外，第三道山形带在区底就断了，不会伸进下一区。四道竖条按 `TEX.pallets4.edges` 量出的边线检查，内框和双重内框按画出来的两道盾形轮廓之间的圈检查（`RINGS`）。生成器放小区分标记前也用同一套检查，只看标记本身（`markCovers()`）。测试会对抽样生成的所有候选跑这项检查，要求零问题；只有几何图形、没有图案的答案在随机抽样里很少，另有一项测试把每种几何图形配上区分标记，在整面、四分、对分里逐一检查。`scripts/lint-layouts.ts` 会跑几千组答案，并按问题类型汇总，改排版参数时用它做回归。

## 图案库与画法

`src/charges.ts` 里每个图案有：英文 blazon 名（单复数）、CK3 配方（一个或多个原版贴图，加颜色角色）、可见范围（从游戏贴图量出来的 alpha 包围盒）。显示名在 i18n 文件里。

**三峰山上的双横十字**（`cross_patriarchal_mount`）是拼出来的：原版匈牙利头衔用的细长双十字 `ce_cross_patriarchal_hungary` 立在 `ce_mount` 的中间那座山上，和原版的 `k_hungary` 一样。山用"第二颜色"：默认取和十字同类、不同于十字的颜色（银十字配金山，红十字配绿山），十字和下面的颜色对比，山也就对比，放在哪里都合规；玩家可以在细节颜色里改，改成和底色同类（如匈牙利的绿山配红底）时，规则检查记为警告而不是错误，候选保留，提示里注明 armes fausses。小图案单独时除了默认的三个，还有"单个居中"（`one`）；十字类单个在前，所以只选双横十字、红底银色时第一个候选就是贝拉三世的 *Gules, a patriarchal cross argent*。

颜色角色：

| 角色 | 含义 |
|---|---|
| `body` | 图案本色 |
| `armed` | 喙、爪、舌、角、蹄、剑柄、斧柄、宝石 |
| `crown` | 冠 |
| `hair` | 头发 |
| `second` | 第二件物品，如第二把钥匙、书、斧刃 |
| `detail` | 门窗 |
| `under` | 图案下面的颜色 |

网页用的图案在 `src/art/<id>.ts`，约定见 `src/art/types.ts`：

- viewBox 的宽高比和游戏贴图的可见范围一致，图形要贴满这个框。
- 颜色只能来自角色。
- 风格是平涂加深色描边和少量内线。
- 必须是原创，不描摹游戏贴图。

原版没有的图案用原版零件拼。**少女鹰**的拼法如下：

1. 原版的鹰 `ce_eagle`；
2. 头发颜色的大椭圆把整个鹰头（喙、舌、冠羽）盖住，两侧再各一个小椭圆，是垂到肩上的两缕头发；
3. 身体颜色的椭圆当脸，下沿和鹰的脖子相连；
4. 五官用原版的小圆片和方块拼：两只眼睛、两道眉、鼻子、嘴，颜色是黑色（脸是黑色时用白色，颜色角色 `features`）；
5. 小冠 `ce_crown_small` 戴在头发上。

没有用底色去"擦掉"鹰头，所以放在任何底上都成立，白鼬皮底也一样。网页版（`src/art/maiden_eagle.ts`）按同一组坐标逐件画，只多了描边。持剑狮（戴冠立狮加原版的剑）、挪威持斧狮的王冠也是这样补上的。

**用方块拼的图案。** 原版零件拼不出来、又必须和史料原画一致的图案，按原画转成原版方块 `ce_block_02`。目前只有"手抄本戴冠立狮"：取自 Lord Marshal's Roll 里保加利亚国王的纹章。狮身轮廓从原画照片里分出来，王冠和五官按原画手工描过，再按 192、112、64 三种格子合并成尽量少的矩形，存在 `src/art/raster/lion_manuscript.json`。转换是一次性做的，仓库里只留结果，不留照片。

- 图层顺序：边缘过渡色（图案色和底色各一半，相当于抗锯齿）、狮身、墨线（八成黑）、王冠。颜色由导出器按实际底色现算，写成 `rgb { … }`。
- 导出器按图案在盾上的大小挑格子：每格不超过盾宽的 1/300，取满足条件的最粗一档。占满盾面时约 640 个方块，放在四分区里少得多。
- 网页示意图直接把同一份方块数据画成 SVG，所以网页和游戏完全一致。
- 图层很多时（超过 1200 个），CK3 代码下方会提示：游戏能正常读取，但配置较低的电脑上可能变慢。

## 国际化

- 界面文字、问题、选项、图案名、王国名和年代说明、历史说明、描述语法片段都在 `src/i18n/*.json` 里。
- 生成器只产出消息（key + 参数），不产出文字。
- 两种语言语法差异较大的部分（量词、冠词、复数）在 `src/describe.ts` 里处理。
- 英文 blazon 是纹章学的技术描述，和 CK3 代码一样不翻译。
