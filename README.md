# CK3 纹章工坊 · CK3 Heraldry Workshop

回答几道关于家族生平的问题，得到一面**符合真实纹章学规则**的纹章，并导出能粘贴进《十字军之王 III》纹章设计器的代码。只用原版贴图，不需要 mod，不影响联机。

*Answer a few questions about your family's story and get a coat of arms that follows real heraldic rules, exported as code you can paste into the Crusader Kings III coat of arms designer. Vanilla textures only — no mod.*

**在线使用：<https://ikuyo.dev/ck3-heraldry/>**

界面支持中文和英文（右上角切换，或在网址后加 `?lang=en`）。

## 使用

在首页选择你在 CK3 里的身份和地域，答题，从右侧挑一种排法，点「复制」，再到游戏的纹章设计器里点「粘贴」。

目前完成的是**西欧统治者**。神职、商人和其他地域（拜占庭、伊斯兰、草原、印度、中华、日本）的规则各不相同，会各做一个页面。

- **保存**：按名字存在浏览器里（localStorage）。
- **分享**：分享链接包含全部回答和选中的排法。
- **不考虑历史真实性**：解除年代、头衔和色彩规则的限制；CK3 的技术限制仍然保留。
- **精确预览**：网站自带的图案是示意图，只用来看结构；因为版权，网站不能附带游戏贴图。点「载入游戏贴图」，选择本机的游戏目录，预览就会用原版贴图画，和游戏里一样。贴图只在浏览器里读取，不会上传；第一次打开设计器时会提示。

## 功能

- **图案**：66 个，主图案按系列选变体，如立狮、戴冠狮、持剑狮、照手抄本原画还原的保加利亚狮、英格兰式行狮、波希米亚双尾狮、单头鹰、双头鹰、少女鹰，以及八种十字。
- **领主**：40 个王国和诸侯，按年代使用当时的纹章。领主可以影响配色、借出图案、放进盾头，或者以恩赐角区、恩赐纹章的形式出现。
- **生平**：起家方式、十字军与朝圣、宣称、爵位与现有头衔（作为领地纹章分区），以及区分标记（长子、次子到五子、私生）。
- **排法**：单个或成组的图案、几何图形、盾面分割、白鼬皮、线条变体等。家族名决定默认的几何图形和线条，所以每个存档的结果都不同。

网站另有三个页面：**示例**（贡扎加、库特奈、克莱尔、内维尔等可以复现的历史纹章）、**规则与出处**、**版权与许可**。

## 设计原则

- **玩家只讲家族故事，纹章的形式由系统决定。** 每道题对应一种真实存在过的纹章机制，不用"红色代表勇气"这类后人附会的象征。
- **构造即正确。** 颜色按角色分配，生成结果不会违反色彩规则。几个愿望冲突时，列出所有合规的解法，并写明哪些愿望没能放下。
- **图案库双重准入。** 每个图案要同时有纹章学定义和 CK3 实现；原版没有的图案用原版零件拼。
- **历史合理性只提示，不限制。**

## 开发

```sh
pnpm install
pnpm dev      # 本地开发
pnpm check    # 类型检查 + 测试
pnpm build    # 构建静态站到 dist/
```
